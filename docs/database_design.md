# Database Design


## Patient


患者基本信息


字段：

|字段|说明|
|-|-|
|id|患者编号|
|age|年龄|
|gender|性别|
|location|地区|



## Cancer Profile


癌症信息


字段：

|字段|说明|
|-|-|
|cancer_type|癌症类型|
|subtype|具体类型|
|stage|分期|
|TNM|TNM信息|



## Treatment Status


治疗状态


字段：

|字段|说明|
|-|-|
|surgery|是否手术|
|chemotherapy|是否化疗|
|current_stage|当前阶段|



## Knowledge Base


医学知识


字段：

|字段|说明|
|-|-|
|title|资料名称|
|type|指南/视频/文章|
|source|来源|
|content|内容|
