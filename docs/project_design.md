# GI-Onco Navigator 项目设计


## 1. 项目目标

GI-Onco Navigator 是一个面向胃肠肿瘤患者的循证信息导航系统。

目标：

将医学指南、患者教育资料、专家交流内容进行结构化整理，
帮助患者理解自身疾病阶段，并获得可靠的信息导航。


## 2. 当前开发阶段

Version: v0.1


当前目标：

完成结直肠癌术后患者信息导航 Demo。


## 3. 核心流程


患者信息

↓

疾病分类

↓

治疗阶段判断

↓

医学知识检索

↓

AI生成解释

↓

返回引用来源
