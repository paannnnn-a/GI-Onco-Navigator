# GI-Onco Navigator

胃肠肿瘤术后循证导航系统

## 项目介绍

GI-Onco Navigator 是一个面向胃肠肿瘤患者的开源智能导航平台。

项目目标：

将临床指南、患者教育资料、专家交流视频等医学知识进行结构化整理，通过人工智能技术帮助患者更好地理解自身疾病阶段，并获得可靠的信息导航。


## 项目背景

胃癌、结直肠癌等消化道肿瘤患者在术后阶段通常面临：

- 不清楚自己当前治疗阶段
- 难以理解医学指南
- 网络信息质量参差不齐
- 缺少个性化的信息整理


本项目希望构建一个：

患者信息管理 + 医学知识库 + AI循证检索 + 康复导航

系统。


## 核心功能规划

### 1. 患者信息管理

记录：

- 癌症类型
- TNM分期
- 手术情况
- 当前治疗阶段
- 地区信息


### 2. 医学知识库

整合：

- CSCO指南
- NCCN指南
- 患者教育材料
- 专家交流视频


### 3. AI循证助手

实现：

- 根据患者情况检索相关知识
- 提供来源引用
- 避免无依据回答


### 4. 患者治疗路径导航

帮助患者了解：

- 当前阶段
- 下一步需要关注的问题
- 复查和康复方向
